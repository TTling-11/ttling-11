# 谭美玲｜个人简历网站

这是谭美玲的个人简历与作品集网站，展示 AI 产品运营、内容策划、媒体实践、代表作品与足球经历。

线上访问：https://tan-meiling-portfolio.sturdy-rice-4285.chatgpt.site

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

启动后，在浏览器中打开终端显示的本地网址，通常为 `http://localhost:5173`。

macOS 用户也可以直接双击仓库中的 `启动网站.command`。

## 主要目录

- `app/`：页面结构与样式
- `public/`：个人照片、足球照片、作品图片和视频
- `scripts/`：构建与校验脚本
- `worker/`：部署入口

更多说明请查看 `README-本地使用说明.md`。
